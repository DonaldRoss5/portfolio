# My Portfolio

A React site that shows the projects I built in Level 2.

## Components

| Component | What it shows | Where its values come from | What it remembers |
| --- | --- | --- | --- |
| `Header` | my name | written in the component |
| `Hero` | my hero photos | `heroPhoto`, which calls `imageUrl` | which photo is showing, and whether it is in color |
| `ClickLabPortfolioCard` | one project: its name, description, and two links | variables inside the component | its likes, and whether it shows more |
| `Fortune` | a random fortune | a list and `randomNumber` | which fortune is showing |

| `DataPlaylistPortfolioCard` | one project: its name, description, and two links | variables inside the component | its likes |
| `Footer` | © year and my name | `new Date()` |

## What I'm adding next

- a New Fortune button

## Built with

React, Vite, Bun, and Pico CSS.
